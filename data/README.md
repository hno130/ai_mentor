# 데이터 안내

이 공개 저장소에는 `examples/courses.json`의 **가상 교과목 예시**만 포함되어 있습니다. 실제 전북대학교 강의나 개설 정보를 의미하지 않으며, 서버에서 자동으로 로드하지 않습니다.

복구된 ZIP에는 강의계획 데이터(JSON/CSV/XLSX), DB 파일, 여러 FAISS 인덱스가 섞여 있었습니다. 공개본에는 데이터 구조만 남겼습니다. 원본 데이터와 인덱스는 원래 ZIP에 보존되어 있습니다.

## 검색 기능을 복구할 때 필요한 작업

1. `Agent/AllAgent.py`의 검색·학과 추천 메서드를 복구합니다.
2. MySQL 테이블 스키마와 데이터 적재 절차를 정의합니다. ZIP의 `.db` 파일이 현재 MySQL 서버를 그대로 대체한다고 가정하면 안 됩니다.
3. 강의별 식별자, 데이터 기준 연도·학기, 출처, 갱신일을 기록합니다.
4. 전처리 → 임베딩 생성 → FAISS 인덱스 구축 스크립트를 추가합니다.
5. 임베딩 모델명, 차원, 정규화 여부, 거리 함수, 인덱스 행과 원본 레코드의 대응 관계를 함께 저장합니다.
6. 다른 임베딩 모델로 만든 인덱스를 재사용하지 않고 동일한 설정으로 재구축합니다.

원본 `setting.py`에는 OpenAI 임베딩과 E5 임베딩이 함께 존재했습니다. 어떤 인덱스가 어떤 모델로 생성됐는지는 복구된 소스만으로 확정할 수 없습니다.

`DATA_DIR` 환경변수로 외부 데이터 폴더를 지정할 수 있습니다. 현재 웹 앱에는 이 데이터와 실제 검색을 연결하는 구현이 빠져 있습니다.
