## 복구본에서 발견한 문제

1. `AllAgent.py`가 `Agent.py`와 같은 내용이며, `AllAgent` 클래스와 검색 메서드가 빠져 있었습니다.
2. `config.py`에 실제 DB 연결 주소와 비밀번호가 들어 있었습니다. 공개본은 환경변수로 대체했습니다.
3. `DatabaseConnection.py`가 import 시점에 외부 DB를 연결했습니다.
4. 스트리밍 응답의 생성기가 실행되기 전에 DB를 닫는 흐름이 있었습니다.
5. 프런트엔드가 특정 서버 IP로 요청했으며, 완료 이벤트를 받은 뒤 SSE 연결을 닫지 않았습니다.
6. 배열을 Python 문자열 표현으로 전송하고 정규식으로 해석했으며, 공백을 제거하는 처리도 있었습니다.
7. 사용자 입력과 과목 설명을 `innerHTML`로 삽입했습니다.
8. 사용하지 않는 UI 사본, 개발 설정, 캐시, 여러 데이터·인덱스 버전이 함께 들어 있었습니다.
9. 실행에 사용하는 Quart가 원본 의존성 목록에 빠져 있었습니다.
